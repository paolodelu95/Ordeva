Ciclo attivo

Dal preventivo alla fattura, senza ricopiare niente

Ogni documento nasce da quello precedente: un preventivo diventa ordine, l'ordine diventa DDT, il DDT diventa fattura, mantenendo righe, prezzi e riferimenti.

  • Preventivi con validità e conversione in ordine
  • Ordini cliente con avanzamento (aperto, evaso)
  • DDT e fatture, anche generate da più DDT
  • Note di credito collegate alla fattura
  • Fatture ricorrenti con emissione programmata

Fatturazione elettronica

Fattura elettronica e Sistema di Interscambio

Ordeva genera il file XML conforme e tiene traccia di dove si trova ogni fattura: da inviare, inviata, consegnata, accettata, rifiutata o scartata.

  • XML per fatture, note di credito e autofatture
  • Stato SDI aggiornato per ogni documento
  • Import delle fatture passive da file XML

I tuoi dati non lasciano il tuo computer

Ordeva non ha un server. Non c'è un account, non c'è sincronizzazione forzata, non c'è telemetria. Quello che inserisci resta in un file locale che controlli tu.

Archivio locale

Un unico file per azienda, sul tuo disco. Puoi tenerne più di uno, copiarlo, spostarlo, metterlo su un tuo NAS.

Password cifrate

Il portachiavi integrato protegge le credenziali con una master password dedicata e cifratura AES-256-GCM.

Backup nelle tue mani

Esporti e reimporti quando vuoi. Nessun rischio che un servizio chiuda e si porti via i tuoi archivi.

Cosa esce dal PC

Solo il controllo aggiornamenti verso GitHub e le integrazioni che attivi tu. Nient'altro. Dettagli nella privacy.

Domande frequenti

Ordeva è davvero gratis?
Sì. È software libero con licenza AGPL-3.0. Non c'è un prezzo di licenza, un abbonamento o un limite di documenti, utenti o aziende gestite.
Funziona senza connessione a internet?
Sì. Tutte le funzioni di gestione funzionano offline. Serve la connessione solo per il controllo degli aggiornamenti e per le integrazioni facoltative (invio allo SDI, Google, marketplace).
Dove finiscono i miei dati?
In un file sul tuo computer, che scegli tu dove salvare. Non esiste un server di Ordeva che li riceve o li conserva. Puoi fare copie e backup come preferisci.
Che sistemi operativi supporta?
Windows (installer .exe e .msi), macOS (.dmg, sia Intel sia Apple Silicon) e Linux (.AppImage e .deb).
Posso emettere fatture elettroniche?
Ordeva genera il file XML conforme e ne traccia lo stato allo SDI. La trasmissione avviene tramite il canale che scegli. Può anche importare le fatture passive ricevute in formato XML.
Posso partire da un altro gestionale?
Sì. Clienti, fornitori e prodotti si importano da file Excel. Le fatture passive si importano dai file XML.
