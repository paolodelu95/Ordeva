Ordeva

Gestionale ERP desktop che gira interamente sul tuo computer — anagrafiche, magazzino, fatturazione elettronica, ciclo attivo e passivo, agenda, scadenzario.

I tuoi dati restano sul tuo dispositivo. Non c'è un account, non c'è un server di Ordeva che riceve o conserva i dati della tua attività. L'archivio è un file locale sul tuo computer.

Integrazioni opzionali

Ordeva può collegarsi, se e quando lo decidi tu, ad alcuni servizi esterni usando le tue credenziali:

  • Google Calendar — sincronizzazione appuntamenti dell'agenda
  • eBay, Amazon, Shopify — importazione degli ordini conclusi per scaricare il magazzino e alimentare le statistiche di vendita

Il collegamento avviene direttamente tra il tuo computer e il servizio scelto. Le credenziali sono salvate solo in locale. Vedi la informativa privacy per i dettagli.
